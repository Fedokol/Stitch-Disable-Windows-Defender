# Windows Defender Toggle

Приложение на Python для **включения и отключения защиты Microsoft Defender**
(защита в реальном времени) в Windows 10 / 11.

Два режима работы: привычное **окно с кнопками** (tkinter) и **командная строка**
для скриптов и автоматизации.

---

## Быстрый старт

1. Сохраните файл `defender_toggle.py` на компьютер с Windows.
2. Запустите его одним из способов:
   * двойной клик по **`Запустить от администратора.bat`** — откроется окно приложения;
   * или в PowerShell / cmd от имени администратора:
     ```
     python defender_toggle.py
     ```
3. Нажмите **⛔ ОТКЛЮЧИТЬ защиту** или **✅ ВКЛЮЧИТЬ защиту**.

Если прав администратора нет, приложение само покажет окно UAC и перезапустится.

> Python должен быть установлен (3.8+). Стандартная библиотека — всё, что нужно:
> `tkinter`, `subprocess`, `ctypes` уже входят в официальный установщик Python для Windows.

## Командная строка

| Команда | Что делает |
|---|---|
| `python defender_toggle.py` | открыть графический интерфейс |
| `python defender_toggle.py status` | показать текущее состояние Defender |
| `python defender_toggle.py off` | отключить защиту в реальном времени |
| `python defender_toggle.py on` | включить защиту в реальном времени |
| `python defender_toggle.py toggle` | переключить (вкл ↔ выкл) |
| `python defender_toggle.py exclude "C:\Games"` | добавить папку в исключения |

**Ключи**

| Ключ | Назначение |
|---|---|
| `--extra` | вместе с real-time управлять поведенческим мониторингом, проверкой скриптов, архивов и скачанных файлов |
| `--json` | выводить результат в JSON (удобно для своих скриптов) |
| `--force` | не спрашивать подтверждение при отключении |
| `--no-admin` | не запрашивать повышение прав автоматически |

**Примеры**

```bat
:: временно выключить защиту для установки тяжёлой сборки
python defender_toggle.py off --extra --force

:: узнать состояние в JSON
python defender_toggle.py status --json

:: включить обратно
python defender_toggle.py on --extra
```

## Важно про Tamper Protection

С Windows 10 20H1 / Windows 11 защита настроек Defender контролируется функцией
**«Защита от несанкционированного вмешательства» (Tamper Protection)**. Пока она
включена:

* `Set-MpPreference` может вернуть ошибку `0x80070005 / Unauthorized access`;
* даже успешное отключение Windows **сама вернёт обратно** через несколько минут.

Поэтому приложение:

1. использует официальный модуль PowerShell **Defender** (`Set-MpPreference`),
   а не правку реестра — ключ `DisableAntiSpyware` в современных версиях игнорируется;
2. читает и показывает состояние Tamper Protection;
3. при блокировке выдаёт понятную инструкцию на русском.

Чтобы отключить защиту надолго:
**Пуск → Безопасность Windows → Защита от вирусов и угроз → Параметры защиты
от вирусов и угроз → Управление настройками → Защита от несанкционированного
вмешательства → Выкл.** (это делается только вручную, программно — запрещено системой).

## Как это устроено внутри

| Слой | Реализация |
|---|---|
| Получение статуса | `Get-MpPreference` + `Get-MpComputerStatus` → JSON → парсинг в Python |
| Переключение | `Set-MpPreference -DisableRealtimeMonitoring $true/$false` |
| Доп. компоненты | `-DisableBehaviorMonitoring -DisableIOAVProtection -DisableScriptScanning -DisableArchiveScanning` |
| Исключения | `Add-MpPreference -ExclusionPath` |
| Права администратора | `ctypes.windll.shell32.IsUserAnAdmin` / `ShellExecuteW("runas")` |
| Запуск PowerShell | `-NoProfile -NonInteractive -ExecutionPolicy Bypass` + `CREATE_NO_WINDOW` (консоль не мелькает) |
| Кодировки вывода | авто-подбор `utf-8 / cp866 / cp1251 / mbcs` — русские сообщения не ломаются |

Ошибки PowerShell переводятся в человекочитаемые сообщения: отказ в доступе,
Tamper Protection, отсутствие модуля Defender, пассивный режим из-за стороннего
антивируса, прочие сбои операции.

## Безопасность и ограничения

* Отключение антивируса **снижает защиту компьютера**. Используйте только когда
  это действительно нужно (установка ПО, тесты производительности, ложные
  срабатывания) и включайте защиту обратно.
* Часто лучше не отключать Defender целиком, а добавить конкретную папку в
  исключения — кнопка «＋ Добавить папку в исключения» делает именно это.
* Если в системе установлен сторонний антивирус (Kaspersky, ESET и т. п.),
  Defender работает в пассивном режиме, и управлять им из этой программы нельзя —
  приложение сообщит об этом.
* Корпоративные политики (Intune / Group Policy) могут жёстко фиксировать
  настройки Defender; локальное изменение в таком случае будет отклонено.
